# パラメーター

KTBPoses がアバターに足すパラメーターです。

| パラメーター | 型 | 同期 | 保存 | 使う量 | 内容 |
|---|---|---|---|---|---|
| `KTBPoses/Pose` | Int | する | しない | 8 bit | 選んでいるポーズの番号（0 は通常） |
| `KTBPoses/Mirror` | Bool | する | する | 1 bit | 左右反転 |
| `KTBPoses/Lock` | Bool | しない | する | 0 bit | 位置固定 |

合わせて **2 個・9 bit** です。ポーズの数が増えても変わりません。1 つのポーズ集に入れられるポーズは 255 個までです。

- ポーズの番号は、メニューの並び順で 1 から振られます。並びを変えて導入し直すと、番号も変わります
- 同じアニメーションをメニューの何か所に入れても、1 つと数えます
- 位置固定は自分の動きにだけ関係するので、同期していません

導入する前に、アバター全体で足りるかどうかを [同期パラメーターの確認](install-avatar.md#parameters) で確かめられます。

!!! note "パラメーターの名前"
    名前はすべて `KTBPoses/` で始まります。ほかのギミックが同じ名前を使っていると、正しく動きません。
