# 困ったとき

## Unity で

### メニューに KTBPoses が無い

**Tools → KyokaToyBox → KTBPoses** にあります。

- 開くと「必要なパッケージ」の案内が出るとき：Modular Avatar 1.18.0 以上と VRChat SDK - Avatars 3.5.0 以上を、VCC で入れてください（[必要なもの](install.md#requirements)）
- メニュー自体が無いとき：プロジェクトのどこかにスクリプトのエラーがあると、ツールが読み込まれません。Console のエラーを直してください

### サムネイルが出ない

上の段でアバターを選んでください。Humanoid のアバターだけ表示できます。

### 「導入できません」と出る

赤い枠に理由が出ています。

- 同期パラメーターが足りないとき：ほかのギミックの同期パラメーターを、表示された bit 数だけ減らしてください。上限に近いときは **ビルドして正確に確認** で実測してください（[同期パラメーターの確認](install-avatar.md#parameters)）
- Humanoid でないアバターには入れられません
- Play モード中は導入できません

### ポーズ集を変えたのに、アバターのメニューが変わらない

[導入し直す](install-avatar.md#reinstall) を押してから、アップロードし直してください。

### 更新したのに、ポーズ集のポーズが増えていない

新しい版で増えた同梱ポーズは、ライブラリには入りますが、今あるポーズ集には入りません（自分で組んだメニューを変えないため）。[ポーズ集](pose-sets.md) タブで追加するか、**同梱から作成** で全ポーズのポーズ集を作ってください（[新しく増えた同梱ポーズ](install.md#update)）。

## VRChat で

### メニューに KTBポーズ が無い・ポーズにならない

- 導入してから、アップロードし直したか確かめてください
- 椅子などに座っているあいだは、ポーズをとりません（立ち上がると、選んでいるポーズに戻ります）

### 手が顔にめり込む・足が浮く

同梱のポーズは、制作に使ったアバターの体型に合わせてあります。[同梱ポーズを体型に合わせ直す](library.md#refit) で、自分のアバターに合わせられます。

### ポーズのまま滑って動いてしまう

**設定 → 位置固定** を ON にすると、ポーズ中は動かなくなります（[位置固定](in-vrchat.md#lock)）。

### 段差を上り下りすると、足が伸び切る・曲がってポーズが崩れる

2.1 までの不具合です。着地したときに VRChat が足と腰をトラッキングに戻すためで、2.1.1 で直り、2.1.2 で一瞬の崩れも出なくなりました（[トラッキングをかけ直す理由](how-it-works.md#keep-tracking)）。最新版に [更新](install.md#update) して、導入済みのアバターで [導入し直す](install-avatar.md#reinstall) を押してから、アップロードし直してください。

### ポーズをとると、アバターがプレイヤーの横にずれる

2.1.1 までの同梱ポーズでは、片足に重心をかけるポーズなどで、体が視点から横にずれていました。2.1.2 で、体全体の重心が視点の真上に来るように直しました（[ポーズの位置](poses.md#position)）。最新版に [更新](install.md#update) してください（アニメーションが新しくなるので、導入し直さなくても変わります）。

### ポーズ中にエモートが出ない

ポーズはエモートと同じ Action レイヤーで再生するので、ポーズ中はポーズが優先されます。**通常に戻す** でポーズをやめてください。

## 旧版から移行するとき

KTBPoses の旧版（`KTBPoses.prefab` をアバターに置く版）が入っているアバターに導入すると、確かめたあとで旧版を外して置き換えます。パラメーターの名前が同じなので、両方は入れられません。

旧版のファイル（`Assets/KyokaToyBox/KTBPoses` の `KTBPoses.prefab`・`KTBPoses_Action.controller`・`Icons`）は、今の版では使いません。旧版を置いているアバターが無ければ消せます。
