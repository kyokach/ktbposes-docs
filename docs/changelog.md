# 更新履歴

## 2.1.3（2026-11-14）

同梱のポーズを 6 つ直しました（[同梱のポーズ](poses.md)）。

- ひざに手：前かがみをゆるめ（体の傾きを 49° から 36° に）、ひざを曲げて、手がひざに乗るようにしました
- 指カメラ：両手の L を直角にして指先どうしを合わせ、長方形の枠になるようにしました（両ひじを上げて構えます）
- 頬杖・口元に手・あごピース・考え中：ひじを支える側の腕が体の前に浮かず、ひじが脇腹のあたりに来るようにしました

アニメーションは、更新するだけで新しくなります。アップロードし直してください。メニューのアイコンも新しくするには、導入済みのアバターで [導入し直す](install-avatar.md#reinstall) を押してからアップロードしてください。[同梱ポーズを体型に合わせ直して](library.md#refit) いた場合は、もう一度合わせ直してください。

## 2.1.2（2026-11-13）

- ポーズ中に段差を上り下りしたり着地したりしたときに、一瞬だけポーズが崩れて見えるのを直しました。アニメーションで動かす設定を、0.1 秒ごとではなく毎フレームかけ直します。着地で戻されても同じフレームのうちに戻るので、崩れは画面に出ません（[トラッキングをかけ直す理由](how-it-works.md#keep-tracking)）
- 同梱のポーズを、体全体の重心が左右方向で視点の真上に来るように置き直しました。片足に重心をかけるポーズや、足を横に流して座るポーズで、アバターが横にずれなくなります（[ポーズの位置](poses.md#position)）

更新したら、導入済みのアバターで [導入し直す](install-avatar.md#reinstall) を押してから、アップロードし直してください。[同梱ポーズを体型に合わせ直して](library.md#refit) いた場合は、もう一度合わせ直してください。

## 2.1.1（2026-11-13）

- ポーズ中に段差を上り下りしたり、ジャンプして着地したりすると、足が伸び切る・曲がるなど、ポーズが崩れる不具合を直しました。ポーズ中は、頭・手・腰・足をアニメーションで動かす設定を 0.1 秒ごとにかけ直します（[トラッキングをかけ直す理由](how-it-works.md#keep-tracking)）
- 位置固定のレイヤーの重みを 0 にしました。手持ちのアニメーションにある、表情などの Humanoid 以外のカーブを上書きしません

更新したら、導入済みのアバターで [導入し直す](install-avatar.md#reinstall) を押してから、アップロードし直してください。

## 2.1（2026-11-12）

同梱のポーズが 100 種類になりました。

- ポーズを 74 種類追加（[同梱のポーズ](poses.md)）
    - ピース・ハート・あざといポーズの種類を増やしました
    - ふだんのしぐさ（バイバイ・グッド・腕組み・おじぎ・自撮りなど）
    - カテゴリ「キメポーズ」を追加（モデル立ち・後ろ姿のほか、バレエ・チアリーディング・ヨガでおなじみのポーズ）
    - 「すわる」に正座・横座り・あぐら・ひざ立ち・うつぶせ・あおむけ・横寝などを追加
- 2.0 から更新すると、増えたポーズがライブラリに追加されます。今あるポーズ集は変わりません
- ポーズ集タブに **同梱から作成** を追加。同梱のポーズをすべて、カテゴリごとのサブメニューに入れたポーズ集を作ります
- 寝転ぶポーズのアイコンとサムネイルは、横から見た姿で作るようにしました
- 同梱ポーズを体型に合わせ直すとき、腕が床に入らないようにし、進み具合を表示するようにしました

## 2.0（2026-11-11）

ポーズを管理するツールになりました。

- ツールの画面（**Tools → KyokaToyBox → KTBPoses**）を追加
    - ポーズ集：ポーズ集のアセットの作成・複製・削除と、メニュー（サブメニュー）の編集
    - アニメーション：クリップ・フォルダ単位での追加、名前の変更、タグ、検索と絞り込み
    - アバターに導入：導入・導入し直す・取り外す、同期パラメーターの確認（見積もり・ビルドでの実測）
- 導入するアバターの姿で、メニューのアイコンを作るようにしました
- メニューの「設定」に、左右反転と位置固定を追加
- ポーズをとっていないときのステートを Write Defaults ON にして、アバターのエモートや AFK のモーションを上書きしないようにしました
- Modular Avatar が入っていない・古いプロジェクトでは、エラーにせず、必要なパッケージを案内するようにしました
