# 更新履歴

## 2.0（2026-11-11）

ポーズを管理するツールになりました。

- ツールの画面（**Tools → KyokaToyBox → KTBPoses**）を追加
    - ポーズ集：ポーズ集のアセットの作成・複製・削除と、メニュー（サブメニュー）の編集
    - アニメーション：クリップ・フォルダ単位での追加、名前の変更、タグ、検索と絞り込み
    - アバターに導入：導入・導入し直す・取り外す、同期パラメーターの確認（見積もり・ビルドでの実測）
- 導入するアバターの姿で、メニューのアイコンを作るようにしました
- メニューの「設定」に、左右反転と位置固定を追加
- ポーズをとっていないときのステートを Write Defaults ON にして、アバターのエモートや AFK のモーションを上書きしないようにしました
- Modular Avatar が入っていない・古いプロジェクトでは、エラーにせず、必要なパッケージを案内するようにしました

## 1.0（2026-11-10）

- 最初の版。26 ポーズのポーズ集を、Prefab をアバターに置いて使う形
