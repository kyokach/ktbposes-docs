# 仕組み

## アバターを書き換えない

導入で追加するのは、アバターの直下の Prefab 1 つだけです。中身は Modular Avatar のコンポーネントです。

| コンポーネント | 役目 |
|---|---|
| MA Merge Animator | ポーズのアニメーターを、アバターの Action レイヤーに足します |
| MA Parameters | `KTBPoses/Pose`・`KTBPoses/Mirror`・`KTBPoses/Lock` を足します |
| MA Menu Installer・MA Menu Item | Expression Menu にメニューを足します |

アップロードのときに、Modular Avatar がアバターの複製に組み込みます。シーンのアバターと、元のアニメーター・メニュー・パラメーターのアセットは変わりません。Prefab を外せば、導入する前と同じです。

Prefab には、ツールが導入済みのものを見分けるための目印も付いています。アップロードのときに外れるので、アップロードしたアバターには残りません。

## アニメーター

3 つのレイヤーがあります。

| レイヤー | 内容 |
|---|---|
| KTB Poses | ポーズを選ぶと、Action レイヤーの重みを 1 にしてポーズを再生し、頭・手・腰・足・指をアニメーションで動かします。やめると、立ちポーズを経て重みを 0 に戻し、トラッキングを元に戻します |
| KTB Poses Lock | ポーズ中で、位置固定が ON のあいだだけ、移動を止めます |
| KTB Poses Tracking | ポーズ中は毎フレーム、頭・手・腰・足・指をアニメーションで動かす設定をかけ直します |

KTB Poses Lock と KTB Poses Tracking は、モーションの無いレイヤーです。重みは 0 で、設定を切り替えるだけなので、ポーズの見た目には影響しません。

### トラッキングをかけ直す理由 { #keep-tracking }

VRChat の移動のレイヤー（Base）は、ジャンプや落下のあとに着地すると、頭・手・腰・足をトラッキングで動かす設定に戻します。段差を上り下りしたときの小さなジャンプでも起きます。ポーズの設定はポーズに入ったときの 1 回だけなので、そのままだと着地のあと足と腰がトラッキングで動き、足が伸び切ったり曲がったりしてポーズが崩れます。

KTB Poses Tracking は、ポーズ中は毎フレーム設定をかけ直します。ポーズが入っている Action レイヤーは Base レイヤーのあとに動くので、着地で設定を戻されても、同じフレームのうちにアニメーションに戻ります。画面には崩れが出ません（2.1.2 から。2.1.1 は 0.1 秒ごとだったため、一瞬だけ崩れが見えました）。

!!! note "立ち姿勢をポーズに置き換えても直らない理由"
    トラッキングで動かしているあいだは、VR では腰の位置がヘッドセットの位置から決まり、足はそこから床まで届くように伸び縮みします。立ち姿勢のアニメーションをポーズに置き換えても、腰と足はアニメーションのとおりにはなりません。そのため、アニメーションで動かす設定を保ち続ける方法にしています。

### Action レイヤーを使う理由

VRChat の FX レイヤーでは、Humanoid のボーン（全身の姿勢）を動かせません。FX レイヤーの既定のマスクが、Humanoid の筋肉をすべて止めているためです。マスクを変えて筋肉を通すと、今度はポーズをとっていないあいだも FX レイヤーが全身の姿勢を上書きし続け、歩きや待機のモーションが出なくなります。

そのため、全身の姿勢を上書きするためのレイヤーである Action レイヤーで、ポーズを再生しています。

### Write Defaults

すべてのステートが Write Defaults ON です。ポーズをとっていないときのステート（モーションなし）が、下のレイヤー（アバターのエモートや AFK）をそのまま通すためです。

## サムネイルとアイコン

ツールのサムネイルとメニューのアイコンは、アバターの複製をプレビュー用のシーンに作って描きます。シーンのアバターは動かしません。

## パラメーターの実測

「ビルドして正確に確認」は、アバターの複製を一時的なシーンに作り、Modular Avatar などのビルドを実際に通して、Expression Parameters を数えます。終わったら、複製とシーンを消します。
